# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

---

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3360 - [LEARNING LOGS] หั่นขนมปัง
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
	681209	

```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
1-3 hours
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
มีขนมปังเป็นสี่เหลี่ยมผืนผ้า กว้าง W สูง H เอามีดมาหั่น 2 ชุด
มีดแนวตั้ง M ใบ หั่นลงมาจากบนลงล่าง ระบุตำแหน่งตามแกน X
มีดแนวนอน N ใบ หั่นตัดขวาง ระบุตำแหน่งตามแกน Y
มุมล่างซ้ายของขนมปังคือ (0, 0) มุมบนขวาคือ (W, H)
พอหั่นเสร็จ ขนมปังจะแตกเป็นชิ้นเล็กๆ เรียงเป็นตารางเหมือนช่องตาราง หน้าที่ของเราคือหาว่า ชิ้นที่ใหญ่ที่สุดสองชิ้น มีพื้นที่เท่าไร (พิมพ์ตัวมากก่อน)
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
W H M N แต่ใช้จริงแค่ w กับ h ส่วน M กับ N ใส่ _ ทิ้งไว้ เพราะเรารู้จำนวนมีดจากความยาวของ list ที่รับมาอยู่แล้ว จากนั้นรับตำแหน่งมีดแนวตั้งเก็บใน xs และมีดแนวนอนเก็บใน ys แล้วใส่ขอบของขนมปังเข้าไปด้วย คือเติม 0 ไว้หน้าและ w ไว้ท้ายของ xs กับเติม 0 ไว้หน้าและ h ไว้ท้ายของ ys ที่ทำแบบนี้เพราะขอบซ้าย ขอบขวา ขอบล่าง ขอบบน ก็เป็นเส้นแบ่งของชิ้นขนมปังเหมือนกับมีด ทำให้ระยะระหว่างเส้นติดกันคือความกว้างหรือความสูงของแต่ละชิ้นพอดี จาก sample ได้ xs = [0, 2, 10, 14, 20] และ ys = [0, 1, 6, 8, 10, 12]

ต่อมาใช้ for วนหาระยะห่างระหว่างเส้นติดกัน xs[i + 1] - xs[i] ใส่ list widths ได้ [2, 8, 4, 6] และทำแบบเดียวกันกับ ys ได้ heights = [1, 5, 2, 2, 2] แล้วเรียงทั้งสอง list จากมากไปน้อยด้วย sort(reverse=True) ได้ widths = [8, 6, 4, 2] และ heights = [5, 2, 2, 2, 1] เพื่อให้ตัวที่ใหญ่ที่สุดอยู่หน้าสุด

ชิ้นขนมปังทุกชิ้นคือ กว้างหนึ่งค่า คูณ สูงหนึ่งค่า ชิ้นที่ใหญ่ที่สุดจึงเกิดจากกว้างที่สุดคูณสูงที่สุด คือ widths[0] * heights[0] = 8 × 5 = 40 ส่วนชิ้นที่ใหญ่เป็นอันดับสองต้องต่างจากชิ้นแรกอย่างน้อยหนึ่งฝั่ง จึงมีแค่สองตัวเลือก คือลดฝั่งกว้างลงมาตัวที่สอง widths[1] * heights[0] = 6 × 5 = 30 หรือลดฝั่งสูงลงมาตัวที่สอง widths[0] * heights[1] = 8 × 2 = 16 ตัวเลือกอื่นใช้ค่าที่เล็กกว่าทั้งสองฝั่ง จึงเล็กกว่าสองตัวนี้แน่นอน โค้ดเลยเก็บทั้งสามค่าใส่ areas (สองตัวหลังมี if len(...) > 1 กันไว้เผื่อมีค่าไม่พอ) แล้วเรียงมากไปน้อย ได้ [40, 30, 16] พิมพ์สองตัวแรกคือ 40 30 ตรงกับ Sample Output

กรณีที่ชิ้นใหญ่สุดสองชิ้นเท่ากัน เช่น ความกว้างมากสุดมีสองชิ้นที่เท่ากัน widths[1] จะเท่ากับ widths[0] ทำให้ได้พื้นที่เท่ากันสองตัวตามที่โจทย์บอกว่าเป็นไปได้ และเพราะ M กับ N อย่างน้อย 1 ใบเสมอ จึงมีความกว้างและความสูงอย่างน้อยสองค่า areas จึงมีอย่างน้อยสามตัว ไม่ error ตอนอ่าน areas[1]
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
สรุปแนวคิดคือ ใส่ขอบเข้าไปเป็นเส้นแบ่ง หาระยะห่างเป็นกว้างกับสูงของทุกชิ้น เรียงมากไปน้อย แล้วเลือกพื้นที่ใหญ่สุดกับอันดับสองจากแค่สามตัวเลือก
```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text

```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
